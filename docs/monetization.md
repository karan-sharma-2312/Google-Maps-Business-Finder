# Monetization Plan

## Revenue Channels
- Apify Store listing with usage-based pricing.
- SaaS subscriptions by seat and monthly task volume.
- REST API subscriptions by request quota.
- Enterprise annual license with custom SLA.

## Packaging Tiers
- Starter: discovery + website analysis.
- Growth: add SEO, exports, scheduler, notifications.
- Pro: add AI scoring and agent workflows.
- Enterprise: SSO, custom plugins, dedicated support.

## Productization Tasks
- Add tenant-aware auth and billing events.
- Add hard API quotas and usage metering.
- Add dashboard billing and account controls.
- Add legal docs and DPA support.
